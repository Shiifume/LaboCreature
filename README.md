# LaboCreature

LaboCreature is a school project implementing some feature of a creature-collection game developed with **ASP.NET Core MVC** and **.NET**.

Players can create an account, start their adventure by choosing their first creature, and build their own collection.

## Features

- User registration and authentication.
- Player creation and onboarding.
- Creature selection based on different races.
- Creature collection management.
- Player dashboard.

## Technologies

- C#
- .NET / ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML, CSS and JavaScript

## Project Architecture

The application follows a layered architecture:

- **DAL (Data Access Layer):** Database entities, configurations and repositories.
- **BLL (Business Logic Layer):** Business rules, services and models.
- **WebApp:** MVC controllers, views and user interface.

## Getting Started

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Configure your database connection string.
4. Apply the Entity Framework migrations.
5. Run the WebApp project.
